# 🧠 Fake Face Detection Using Deep Learning

## 🔍 Overview
This project detects whether a given human face is **real** or **AI-generated** using deep learning. With the rise of deepfakes and synthetic media, such detection systems have become essential in verifying image authenticity. The system is trained on a dataset of real faces and GAN-generated (fake) faces using a Convolutional Neural Network (CNN).

---

## 🚀 Features

- ✅ **Binary Image Classification** – Detects if a face is Real or Fake.
- 🧠 **CNN-based Deep Learning Model** – Extracts robust features from images.
- 📊 **Visualization Tools** – Accuracy, loss curves, confusion matrix, and sample predictions.
- 📁 **Clean and Organized Dataset Pipeline** – Ready-to-use structure for training/testing.
